# @lucidcms/types

## v0.6.0 (unreleased)

- Added shared types for frontend preview state and resolved preview metadata.
- Added media status, image preset source and video playback source response types.
- Reworked upload-session types around HTTP, multipart-parts and TUS protocols.
- Split system media adapter reporting into storage and delivery keys.

## v0.5.0

- Integration types updated and error type additions.
- Added the public content account response type and `account:read` integration scope.
- Changed media response translation types to locale-keyed records.
- Dropped `tenant` experiment support.

## v0.4.0

- Updated collection document generics to support collection-specific callback types.
- Added `updatedAt` on `DocumentVersionSummary`.

## v0.3.0

- Added public range custom field types.
- Updated public media response types.
- Added preview session types.

## v0.2.0

- Added new public type contracts used by Lucid core.
